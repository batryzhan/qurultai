# Qurultai engineering guidance

Follow docs/MASTER_SPEC.md and the shared API contract in docs/IMPLEMENTATION.md.
Never present simulated output as empirical research. Never invent citations, provider capabilities, token accounting, or model IDs. Keep credentials server-side. Use tests first for behavior and record actual checks. Backend and frontend have separate ownership during parallel work; coordinate changes to the API contract. No automatic commits, pushes, or publishing are required.
