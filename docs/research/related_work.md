# Related work and proposed contribution

See [verified references](literature_review.md). These comparisons describe approaches, not a comprehensive market survey.

| Approach | Main mechanism | Qurultai comparison |
|---|---|---|
| Single-model answer | One generation | Necessary baseline; lowest orchestration complexity |
| Self-consistency / majority | Independent samples, answer aggregation | Separates sampling benefit from interactive revision; role-diverse voting is not an exact self-consistency replication |
| Du et al. debate | Iterative peer discussion | Prior art for debate; Qurultai must justify protocol and evaluation differences |
| Karpathy LLM Council | Independent responses, peer ranking, chairman | Prior software inspiration; inspectable disagreement and reproducible strategy comparison are intended extensions |
| Lewis et al. RAG | Retrieval-conditioned generation | Evidence access is a separate experimental factor, not automatic verification |

Candidate contributions are a transparent role-based protocol, explicit unresolved conflicts, source-to-claim inspection, and an auditable comparison workflow in a culturally respectful interface. These are implementation goals pending validation. No first-of-kind or scientific novelty claim is established by the cultural framing.
