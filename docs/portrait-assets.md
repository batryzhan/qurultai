# Portrait asset provenance

Generated with the built-in imagegen tool on 2026-10-19 for this project. These are artistic interpretations, not authenticated historical likenesses or photographs. Each portrait was visually inspected and saved as WebP (quality 88, no composition changes) under `frontend/public/images/biys/`.

Vertical portrait. No text, no watermark, no modern accessories, no fantasy armor, no caricature.”

- `tole-bi.webp`: Tole Bi, elderly Kazakh scholar with composed analytical expression, white beard, ivory traditional headwear and dark gold embroidered robe.
- `kazybek-bi.webp`: Kazybek Bi, mature Kazakh scholar with thoughtful critical expression, salt-and-pepper beard, traditional dark headwear and muted teal embroidered robe.

The modern analytical, critical, and synthesis roles are software choices. They do not claim to reproduce these historical figures' views. Original generated PNGs remain in the local Codex generated-images directory; project runtime uses the workspace WebP copies.
